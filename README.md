# Сервис аутентификации (FastAPI + SQLite)

Самостоятельный сервис аутентификации с защитой от ботов. 
Проект реализует регистрацию, авторизацию, работу с сессиями и кастомную математическую CAPTCHA.

## Стек
* **Backend:** Python 3, FastAPI, Uvicorn
* **База данных:** SQLite (асинхронно через `aiosqlite`)
* **Frontend:** HTML, CSS (Тёмная тема, адаптивность), JavaScript (валидация на клиенте)
* **Шаблонизатор:** Jinja2

## Структура проекта
```text
.
├── app.py                 # Главный файл приложения (маршруты, БД, логика)
├── requirements.txt       # Список Python-зависимостей
```

## Запуск без Docker (Локально)

Убедитесь, что у вас установлен Python версии 3.9 или выше.

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите сервер:

```bash
uvicorn app:app --reload
```

Откройте в браузере: http://127.0.0.1:8000

База данных (users.db) будет создана автоматически при первом запуске приложения.

## Запуск через Docker

Убедитесь, что у вас установлен Docker и Docker Compose.

В терминале выполните команду:

```bash
docker compose up -d
```

Откройте в браузере: http://127.0.0.1:8000

Остановить сервер можно командой:

```bash
docker compose down
```

### Запуск через чистый Docker (Альтернатива)

Соберите Docker-образ:

```bash
docker build -t auth-service .
```

Запустите контейнер:

```bash
docker run -d -p 8000:8000 -v $(pwd):/app --name my-auth-app auth-service
```

### Как это запустить?

Для стартадостаточно открыть терминал в папке проекта и написать:

```bash
docker compose up -d
```

Флаг -d (detached) запустит сервер в фоновом режиме, оставив ваш терминал свободным.
